# Loophole Community Rules

A community-driven collection of rules and workflows for [Loophole](https://github.com/loophole-ai/loophole) — the AI IDE that thinks while you code.

Browse, use, and contribute prompts that make Loophole smarter in your projects.

---

## What's Inside

| Folder | What it contains |
|---|---|
| `.loopholerules/` | Rules that shape how Loophole behaves in your project |
| `workflows/` | Step-by-step workflows for common coding tasks |

---

## How to Use

1. Find a rule or workflow you like.
2. Copy the file into your project's `.loopholerules/` folder.
3. Open your project in Loophole — it picks it up automatically.

---

## Contributing

Got a rule or workflow that's been helpful? Share it with the community!

1. Fork this repo.
2. Add your `.md` file inside `.loopholerules/` or `workflows/`.
3. Name it using `kebab-case` (e.g., `no-console-logs.md`).
4. Open a Pull Request — we'll review and merge it.
